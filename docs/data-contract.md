# Synthetic data contract

`data/support_tickets.csv` is generated by `scripts/generate_data.py`. It does
not derive from a customer, employer, support system, or private repository.

## Provenance

| Property | Value |
|---|---|
| Generator | `scripts/generate_data.py` |
| Seed | `42` |
| Rows | `960` |
| Date window | 2026-01-05 through 2026-03-29 |
| Source license | Project-generated under the repository MIT license |

## Columns

| Column | Type | Nullable | Contract |
|---|---|---:|---|
| `ticket_id` | string | no | Sequential synthetic ID, `TKT-0001` format |
| `created_at` | date | no | ISO 8601 date inside the fixed generation window |
| `week` | string | no | ISO week, `YYYY-Www` |
| `queue` | enum | no | `Account`, `Playback`, `Billing`, or `Devices` |
| `category` | enum | no | One of three public fixture categories per queue |
| `channel` | enum | no | `Chat`, `Email`, or `Phone` |
| `resolution_minutes` | integer | no | Positive synthetic duration |
| `first_contact_resolution` | integer | no | `0` or `1` |
| `csat` | decimal | yes | Blank or score from `1.0` through `5.0` |
| `escalated` | integer | no | `0` or `1` |

## Explicit exclusions

The public contract forbids names, agent identifiers, supervisor identifiers,
emails, phone numbers, account IDs, customer IDs, free-text messages, addresses,
and imported operational records. The privacy test fails if identity/contact
columns or contact-shaped strings appear in public text fields.

## Reproduce and verify

```bash
uv run python scripts/generate_data.py
git diff --exit-code -- data/support_tickets.csv
uv run pytest tests/test_synthetic_data.py
```

The production health endpoint publishes the current row count, seed, source
path, and SHA-256 digest: <https://queryproof-theta.vercel.app/api/health>.
