# Security policy

## Supported versions

Only the latest commit on `main` and the latest release are supported.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue for secrets, personal data, or a vulnerability that could be
actively exploited.

Include the affected route or commit, reproduction steps, impact, and any safe
mitigation you identified. Please do not access data that is not yours or perform
availability testing against the public deployment.

## Public data guarantee

The repository must contain only generated synthetic records and public project
documentation. If potentially real personal or operational data is discovered,
stop redistribution and report it privately.
